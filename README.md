# Tetris

Классический Тетрис на **Vue 3**, **TypeScript** и **Vite** — с темами оформления, адаптивным полем и сохранением выбранного стиля.

**Играть онлайн:** [gh0st0fwar.github.io/Tetris](https://gh0st0fwar.github.io/Tetris)

---

## Управление, правила и интерфейс

### Как начать

1. Откройте игру по ссылке выше или запустите локально (`npm run dev`).
2. Нажмите **«Начать игру»** на стартовом экране.
3. Управляйте падающей фигурой с клавиатуры.

### Управление

| Клавиша | Действие |
| --- | --- |
| `←` | Сдвиг фигуры влево |
| `→` | Сдвиг фигуры вправо |
| `↓` | Ускоренное падение на одну клетку |
| `Пробел` | Поворот фигуры на 90° по часовой стрелке |

Управление работает только во время активной игры.

### Правила

- На поле появляются фигуры четырёх типов: **I**, **O**, **L**, **T**.
- Фигуры падают автоматически с интервалом **1 секунда**.
- Когда фигура больше не может двигаться вниз, она **фиксируется** на поле.
- Если строка полностью заполнена, она **исчезает**, а блоки сверху **опускаются**.
- Если новая фигура не может появиться — **Game Over**.
- После проигрыша нажмите **«Рестарт»**, чтобы очистить поле и вернуться к стартовому экрану.

### Интерфейс

| Элемент | Описание |
| --- | --- |
| **Игровое поле** | Сетка 10×16 (средний размер). Размер клеток подстраивается под высоту окна. |
| **Стартовый экран** | Кнопка «Начать игру» поверх поля. |
| **Game Over** | Заголовок и кнопка «Рестарт». |
| **Панель «Стиль»** | Переключение между пятью темами оформления. |

### Темы оформления

Каждая тема меняет не только палитру, но и характер интерфейса: форму клеток, фон страницы, шрифты, тени и декоративные эффекты.

| Тема | Описание |
| --- | --- |
| **Neon** | Cyberpunk: тёмный фон, неоновые cyan и pink акценты, свечение блоков |
| **Terminal** | CRT-монитор: чёрный экран, фосфорно-зелёный текст, scanlines, квадратные «пиксельные» клетки, моноширинный шрифт |
| **Sketch** | Светлый блокнот: лист в клетку, карандашные контуры, синие и красные заливки, пунктирные кнопки |
| **Woodcraft** | Деревянная доска: янтарные блоки с 3D-фаской, тёплые коричневые тона, объёмные кнопки |
| **Synthwave** | 80-е: закатное небо, солнце на горизонте, перспективная сетка пола, хромовый заголовок, neon cyan + pink |

Выбранная тема сохраняется в `localStorage` (ключ `tetris-theme`) и остаётся активной после перезагрузки страницы (**F5**).

## Документация по коду

### Стек

- **Vue 3** — UI и реактивность
- **TypeScript** — типизация игровой логики
- **Vite** — сборка и dev-сервер
- **SCSS** — стили (BEM, CSS-переменные для тем)
- **@fontsource** — шрифты Orbitron и Rajdhani

### Структура проекта

```
src/
├── App.vue                 # UI: оверлеи, переключатель тем, связь с Tetris
├── main.ts                 # Точка входа, подключение шрифтов и стилей
├── composables/
│   └── useLocalStorage.ts  # Сохранение настроек в localStorage
├── constants/
│   └── themes.ts           # Список тем и валидация ThemeId
├── scss/
│   ├── main.scss           # Глобальные стили
│   ├── variables.scss      # SCSS-переменные (отступы, шрифты)
│   ├── game.scss           # BEM-блок .game, базовые CSS-переменные компонентов
│   └── themes.scss         # Пять тем: палитра, формы, фоны, theme-specific overrides
└── ts/
    ├── tetris.ts           # Ядро игры: поле, цикл, строки, game over
    ├── pivot.ts            # Активная фигура: движение, поворот, отрисовка
    ├── pieceType.ts        # Типы фигур и их формы (offsets)
    ├── abstractCell.ts     # Базовая клетка и CSS-классы состояния
    └── cell.ts             # Клетка игрового поля
```

### Архитектура

**`Tetris`** — центральный класс. Создаёт DOM-поле, хранит двумерную сетку `Cell[][]`, управляет игровым циклом и обрабатывает клавиатуру.

**`Pivot`** — текущая падающая фигура. Знает тип (`PieceType`), позицию `(x, y)` и угол поворота. Методы `moveLeft`, `moveRight`, `moveDown`, `rotate` проверяют коллизии через `canMoveWith` (с учётом собственных клеток фигуры) и перерисовывают блоки.

**`Cell` / `AbstractCell`** — одна клетка сетки. Состояние задаётся классами BEM:

- `game__cell--filled` — зафиксированный блок
- `game__cell--active` — блок активной фигуры

Цвета и оформление не зашиты в TypeScript — они задаются CSS-переменными и модификаторами `.game--theme-*` в `themes.scss`.

### Темы (код)

Идентификаторы тем в `constants/themes.ts`: `neon`, `retro`, `ocean`, `sunset`, `minimal`. В интерфейсе они отображаются как **Neon**, **Terminal**, **Sketch**, **Woodcraft**, **Synthwave**. Класс темы на корневом элементе: `game--theme-{id}`.

### Игровой цикл

```
startGame()
  → spawnPiece()        // случайная фигура в центре сверху
  → startFalling()      // setInterval каждые 1000 ms

каждый тик / ArrowDown:
  moveDown() === false
    → lockPiece()       // активные блоки → зафиксированные
    → clearFullRows()   // очистка заполненных строк
    → spawnPiece()      // новая фигура или gameOver()
```

### Размеры поля

Перечисление `Size` в `tetris.ts`:

| Размер | Сетка |
| --- | --- |
| `Small` | 7 × 11 |
| `Medium` | 10 × 16 *(используется в App.vue)* |
| `Large` | 16 × 24 |

Высота клетки вычисляется из `window.innerHeight` с учётом вертикальных отступов (30 px сверху и снизу).
